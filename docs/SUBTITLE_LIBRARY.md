# 자막 라이브러리와 회차 묶음

## 전 시즌 보관소·완료 번역 연결 (2026-10-24 후속 수정)

이전에는 확장 IndexedDB의 회차만 나열해 headless로 확보한 156회차가 빠지고, 작품 메타데이터를 직접 입력하지 않은 회차는 `작품 미지정`으로 표시됐다. 별도 실행기의 E06 Astra high 번역도 파일로만 존재했다.

현재 라이브러리는 열릴 때 로컬 브리지에 연결해 인증된 `/extension/library/archive` 목록을 읽고 회차별로 원본 바이트·원문 해시·번역 요청/응답·B VTT를 검증한 자료를 가져온다. 실제 발견 목록의 작품·시즌·회차·회차 제목을 채우며, 직접 지정한 메타데이터와 현재 원문/A/B·표시 설정은 보존한다. 완료된 번역은 요청과 함께 별도 버전으로 추가하고 `B 보관 · 전편 번역`으로 표시한다. 이후 목록 revision이 바뀐 회차만 다시 가져온다. 모델을 호출하거나 번역을 재실행하지 않는다.

현재 선택한 한글 트랙이 비어 있으면, 현재 영어 원문과 요청·해시·슬롯이 일치하는 완료 B를 선택해 같은 영상의 열린 Netflix 탭에 전달한다. 이미 선택한 A/B가 있거나 사용자가 자막 끄기·영어만 보기를 선택했다면 유지한다. 원본/A와 이전 B 버전, 글자 크기·시간 보정은 보존하고 영상의 재생 위치·배속·재생 상태를 바꾸지 않는다. 보관소 revision이 같아도 라이브러리 로드 시 이 선택 검사를 수행한다. **이 버전 사용**도 한글 표시를 활성화하고 해당 영상에 전달한다.

E06은 처음에 B 버전만 보관되고 실제 표시 트랙이 비어 있어 자막이 나오지 않았다. 위 선택 경로를 수정한 뒤 2026-10-24 19:44 KST, 실제 Netflix E06의 00:40.084에서 B의 동일 시각 cue 39·40이 두 줄로 표시되는 것을 화면과 DOM에서 확인했다. 일시정지·1.25배속을 유지했다. 이 확인은 전체 음성 싱크 검사를 뜻하지 않는다. 개인 근거: `private-subtitles/e06-live-playback-proof.json`과 `.jpg`.

실제 보관소 156회차·279,524개 cue의 공개·클라이언트 병합 검사를 통과했다. E06은 The West Wing · 시즌 2 · 6화 · The Lame Duck Congress, Astra high B 2,236/2,236개로 인식했다. 기존 3회차에서 합성 156회차로 확장되는 UI 경계 검사와 전체 회귀 검사도 통과했다. 실행 중인 브리지의 실제 인증 API도 156회차와 E06 완료 번역을 반환했다. 설치된 확장 IndexedDB의 최종 화면을 직접 관찰한 검증과는 구분한다. 업데이트 전 열려 있던 라이브러리는 페이지를 새로고침해야 새 스크립트를 읽는다.

`PC 수집·번역 자료 가져오기`와 `새로고침`으로 다시 연결할 수 있다. 브리지 오프라인이면 기존 브라우저 자료를 유지한다. 실제 근거는 개인 `library-archive-integration-audit.json`, `library-archive-http-audit.json`, `library-archive-tests.log`에 보존한다. 과거 MCP 작업의 요청 해시가 현재 코어와 맞지 않으면 기존 파일을 고치지 않고 연결 재검사 대상으로 남긴다.

2026-10-24 구현 기준. 팝업의 **자막 라이브러리**는 재생 중인 영상 없이 열리는 확장 내부 페이지다. 기존 자막 작업실은 한 영상의 입력·표시 조절을 담당하고, 라이브러리는 저장한 회차와 버전을 관리한다. 번역 시작이 작업실이나 이 페이지를 자동으로 열지는 않는다.

개인 Pro의 복사+MCP 방식을 유지하며 이후 승인된 [공식 요금제 연동 실행기](CHATGPT_PLAN_USAGE.md)의 완료 결과도 보관소에서 가져온다. Workspace Agents 실계정 적용과 설치된 ChatGPT 확장 식별은 보류한다. 두 항목을 라이브러리·일괄 준비 개발의 차단 조건으로 사용하지 않으며 기존 연결 코드는 보존한다. 실제 영상/음성 검증도 별도 보류 상태다.

## 보관·검색·미리보기

- 확장 IndexedDB의 모든 세션을 작품·시즌·회차, 영어/A/B 버전 수, 부분 번역/보관 상태와 준비된 cue 수로 표시한다.
- 작품명·`S02E03`·영상 ID 검색, 시즌·상태 필터, 선택한 자막의 대사/ID 검색을 제공한다. 작품·시즌·회차 정보는 수정할 수 있으며 모르는 회차는 추측하지 않는다.
- **열기**에서 현재·보관 버전을 선택하고 ID·원래 시작/끝 시각·본문을 미리 본다. EN/A/B 비교는 같은 원래 시각의 활성 cue로 계산한다. 언어별 cue 번호나 개수로 일대일 결합하지 않는다.
- **이 버전 사용**은 선택한 버전을 해당 역할로 저장한다. 바뀌는 이전 자막은 보관한다. EN/B를 수동 선택하면 진행 중 작업의 자동 선택을 중지한다. 재생 중인 영상으로 전달할 때도 영상 ID를 다시 확인하며 위치·배속·재생 여부를 변경하지 않는다.
- **브리지 자료 가져오기**는 기존 허용 Origin·페어링 인증을 거쳐 각 고정 원문/요청을 검사하고 가져온다. 원문과 B를 보관하되 현재 선택한 A/B는 바꾸지 않는다.

자막 내용·언어·요청 ID·출처로 콘텐츠 해시와 버전을 구분한다. 파일명·글자 크기만 바뀌면 새 문안 버전으로 만들지 않는다. 같은 요청의 연속적인 부분 B는 하나의 번역 버전이다. 현재 요청을 교체해도 이전 B의 요청 근거를 함께 보관한다.

검사 표시는 다음과 같다.

| 표시 | 의미 |
|---|---|
| 파일 원문 | 저장된 파일 트랙. 전편 수집 여부를 보증하지 않음 |
| 전편 수집 기록 | 해당 트랙에 보관된 전편 수집 근거가 있음 |
| 연결 미확인 | 비교할 원래 요청이 없거나 해당 요청과 연결되지 않음 |
| 요청·ID·시각 일치 | 해당 요청의 해시/슬롯 계약에 맞춰 cue ID·시각·본문 구조를 검사함 |
| 현재 원문·요청·시각 일치 | 요청 해시를 다시 계산하고 현재 영어 원문·출력 슬롯과 일치함 |
| 다른 원문 버전의 번역 | 원래 요청에는 맞지만 현재 선택한 영어 원문과는 다름. 목록에서 원문 변경으로 분류 |
| 연결 검사 실패 | 요청 해시 또는 보관된 요청과 자막이 맞지 않음. 목록에서 검사 필요로 분류 |

이 상태는 의미 정확성이나 실제 음성 싱크 평가 점수가 아니다. 백업을 읽는 것만으로 Netflix 수집을 다시 수행했다고 판정하지 않는다.

## 내보내기와 백업

선택한 버전을 VTT/SRT로 내보낸다. VTT는 원래 ID·시간을 유지하고 SRT는 원래 시간을 유지하며 순번을 다시 매긴다. 표시 offset/배율을 파일 시간에 적용하지 않는다.

선택 회차 또는 전체 회차를 `ottspeed.subtitle-library-backup` v1 JSON으로 백업할 수 있다. 현재 자막, 이전 버전, 요청 근거, 표시 설정과 보관된 수집 원문이 포함된다. 브리지 페어링 토큰, 공식 Agent 토큰, 실행 상태/자동 재실행 선택은 포함하지 않는다.

복원은 전체 SHA-256과 영상 식별자·요청·트랙을 먼저 검사한다. 최대 100 MB·500회차이며 중복 영상 ID는 거부한다. 하나의 IndexedDB transaction에서 없는 회차만 추가하고, 이미 있는 회차는 건너뛴다. 기존 회차의 A/B를 복원으로 덮어쓰지 않는다. 같은 영상의 다른 버전을 파일에서 병합하는 전용 UI는 후속 범위다.

## 이미 수집한 회차/시즌의 일괄 준비

1. 라이브러리에서 필요한 회차를 선택한다. 여러 회차라면 시즌·회차 정보를 먼저 지정해야 순서를 확정할 수 있다.
2. **선택 회차 번역 준비**는 전편 수집 근거가 있는 Netflix 영어 원문만 받는다. 각 원문을 기존 브리지의 고정 작업으로 준비하고 원문 해시가 같은 작업은 재사용한다.
3. 묶음은 작업 UUID·영상 ID·원문 해시·순서를 별도 파일로 고정한다. 회차별 원문과 진행을 독립적으로 검증하고 재시작 뒤에도 이어받는다. 원문이 사라지거나 달라지면 해당 회차를 차단한다.
4. **묶음 프롬프트 복사**로 일반 ChatGPT의 OTTSpeed 앱에 전달한다. 설정된 [Workspace Agents 공식 연결](WORKSPACE_AGENTS.md)이 있다면 **공식 자동 연결로 요청**을 사용할 수 있다. 미설정은 복사 안내를 표시한다.
5. 한 회차의 전체 문맥 읽기 → 그 회차의 분할 저장 → 전편 확정 → 다음 회차 순서다. 뒤 회차를 앞 회차의 번역 문맥에 먼저 넣지 않는다. 먼저 준비된 B는 기존 수신 워커가 저장한다.

보관된 묶음은 **보관한 묶음 불러오기**에서 다시 선택해 진행을 확인할 수 있다. 목록/선택은 인증된 조회만 하며 번역 재실행이나 현재 자막 선택을 변경하지 않는다.

회차별 진행표에는 준비된 cue 수/전체 수, 저장 분할/전체 분할, 시청 가능 시각과 상태가 표시된다. 원문 읽기·부분 저장·전편 확정을 구분하며 묶음의 합계만으로 각 회차 완료를 추측하지 않는다.

**결과 수신 재개**는 고정 요청·원문을 전부 검사한 뒤 기존 작업의 결과 받기를 등록한다. 새 ChatGPT 요청이나 공식 실행을 시작하지 않는다. 새로 등록한 작업은 원문 스냅샷과 B를 보관하며 현재 선택한 원문·A/B·표시 설정을 바꾸지 않는다. 이미 시청용으로 수신 중인 작업은 기존 정책을 유지한다. 수신 등록은 워커 재시작 뒤에도 유지된다. 보관된 B를 사용하려면 회차의 **열기 → 자막 버전 선택 → 이 버전 사용**으로 선택할 수 있다.

개인 Pro 환경에서는 프롬프트 복사가 기본이다. 공식 연결 준비 상태가 확인되지 않으면 자동 실행 버튼을 숨긴다. 복사 직전에도 묶음의 실행 기록·완료·원문 상태를 다시 조회하며, 이미 접수됐거나 접수 여부가 불명확한 공식 요청을 자동으로 복사 방식으로 바꾸지 않는다. 공식 연결 어댑터는 별도로 보존한다.

작업 묶음 준비는 번역 실행이나 완료를 뜻하지 않는다. 이미 완료된 회차는 재번역하지 않는다. 공식 실행의 접수/종료와 MCP 분할 저장·전편 확정도 구분한다. 새 결과가 도착해도 현재 시청 위치와 배속을 바꾸지 않는다.

Chrome 없이 **기존 브리지 작업**을 묶는 명령도 제공한다.

```powershell
npm run batch:prepare -- JOB_UUID_1 JOB_UUID_2
```

이 명령은 로컬 파일만 읽고 별도의 묶음 파일·프롬프트를 만든다. Netflix 접속, 새 원문 확보, 모델 호출, 공식 Agent 실행은 하지 않는다. 출력의 `externalExecutionStarted`는 `false`다. `OTTSPEED_BRIDGE_DIR`로 개발용 별도 저장소를 지정할 수 있다.

| 설치된 ChatGPT 확장을 직접 호출할 수 있나? | 브라우저 목록에서 Chrome의 확장 기반 연결은 확인. 목록의 연결 인스턴스 ID는 제품 ID/버전이 아니며 정확한 설치 제품은 미확인. 공식 문서가 설명하는 사이드 채팅/탭 문맥 기능만으로 외부 프롬프트 제출 API를 추정하지 않음 |

Chrome 확장 간 통신은 상대 확장이 지원하는 공개 수신 인터페이스가 있어야 한다. 확인되지 않은 내부 메시지·네이티브 호스트 프로토콜·계정 쿠키·비공개 플레이어 API를 사용하지 않는다. 공개 화면 자동 입력/전송도 추가하지 않는다. 일반 ChatGPT MCP는 원문 읽기와 결과 저장에 사용하고, 외부 실행은 게시된 Workspace Agent의 별도 공식 채널로 연결한다.

## 구현 확인과 남은 의존성

로컬 자동 검사 125개, 문법·에셋 검사, 별도 localhost 합성 화면의 실제 IndexedDB 저장/복원 보호와 관리 UI를 확인했다. 실제 EP3 보관 작업의 Chrome 없는 묶음 준비도 확인했다. 합성 화면은 설치된 확장의 저장소/Netflix와 분리한다.

후속 검사에서 요청 해시 재계산, 현재 원문 변경 구분, 보관 묶음 재선택을 추가했다. 관련 검사 13개와 문법·에셋 검사·패키징이 통과했고, 합성 브라우저 화면에서도 정상 연결과 다른 원문 버전의 번역이 별도로 표시되는 것을 확인했다.

설치된 확장의 새 화면 실행, EP4 실제 원문 수집·번역, 음성/영상·번역 의미 평가는 미확인이다. 게시된 Workspace Agent의 API 채널 ID와 전용 토큰이 지정된 설정/환경에 없으므로 실계정 자동 실행도 미확인이다. 기존 터널용 키를 대체 사용하거나 새 권한을 만들지 않는다. 사용자 부재 중 질문·수동 조작 요청 없이 로컬 구현과 조사 기록을 진행한 범위다.

복사+MCP 후속 개발은 전체 자동 검사 **135개**, 문법·에셋 검사·패키징을 통과했다. 합성 브리지 응답과 격리된 IndexedDB를 사용한 브라우저에서 회차별 진행표와 수신 재개 UI를 확인했다. 현재 실제 로컬 브리지에서도 보관된 EP3의 1,831/1,831개 cue와 13/13개 저장·읽기 분할을 확인했고 원래 작업 파일 해시가 유지됐다. 이 조회는 새로운 번역이나 EP4 원문 수집의 성공을 뜻하지 않는다.
