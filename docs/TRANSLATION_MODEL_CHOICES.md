# 자막 번역 모델과 Chat 대화 모드 GPT-6 Pro 경로

2026-10-24 확인. `Chat` 대화 모드의 GPT-6 + Pro 선택과 구독 공유 API의 `reasoning.mode: pro` 요청은 같은 지원 범위를 뜻하지 않는다. API 모델 ID와 Chat 표시 모델의 일대일 대응은 확인하지 않았다.

## 현재 추천과 검증 범위

| 목적 | 후보 | 근거와 실제 확인 범위 |
| --- | --- | --- |
| 사용자 요청대로 Chat 대화 모드 활용 | GPT-6 + Pro | 실제 Chat 선택기에서 GPT-6 체크·Pro·OTTSpeed 앱 동시 선택 확인. 실제 Pro 도구 호출·번역 품질은 별도 검증 필요 |
| 무인 호출에서 품질을 우선한 비교 후보 | `gpt-6-astra`, `reasoning.effort: high` | 계정 목록에 노출. 공식 문서의 범용 고성능 모델 설명에 따른 추천이며 자막 품질 우위의 실측 결과가 아님 |
| 속도와 대량 처리를 함께 고려 | `gpt-6.1-sol` | 공식 구독 연동으로 S02E06 앞 150개 번역 및 ID/시간/완료 검증 성공. 다른 모델보다 번역 품질이 높다는 증거는 아님 |

정치·행정·법률 용어, 부정과 조건, 발언 주체, 인물별 호칭·말투, 반어·말장난·나중에 밝혀지는 정보의 순서, 짧은 표시 시간에서의 가독성을 평가해야 한다. 같은 어려운 장면을 동일 문맥으로 번역해 모델명을 가리고 비교한 뒤 주 번역 모델을 정한다. 단순 ID·시각 검사 통과와 의미 품질을 구분한다. 원본과 A는 고정하고 모델별 B를 별도 버전으로 보존한다.

같은 날 추가 요청으로 `gpt-6-astra` + `high`에서 S02E06 **2,236개 전체**를 실제 번역하고 기존 B 생성·시간/ID 왕복 검증을 통과했다. 1회 요청, 8분 32초, 입력 56,297·출력 29,282 토큰, 표준 API 환산 **$1.522494**였다(캐시 입력 56,064 반영). 이는 전편 실행 성공이며 다른 모델과의 번역 품질 우위 검증은 아니다. 상세 사용량과 구독 실제 차감액의 구분은 [요금제 실행 기록](CHATGPT_PLAN_USAGE.md)을 참조한다.

## 실제 Chat 화면에서 찾은 경로

1. 일반 ChatGPT 새 대화에서 **Chat**을 선택한다.
2. 모델 선택기에 **GPT-6**가 체크돼 있는지 확인하고 추론 수준 **Pro**를 선택한다.
3. `+` → **OTTSpeed 자막 번역** 앱을 첨부한다. 관측 시 Chat·Pro 선택이 유지됐다.
4. 사용자가 준비된 프롬프트를 보내면 ChatGPT가 MCP의 원문 읽기·분할 저장·최종 검증을 수행하도록 요청한다.

이 방식은 ChatGPT 모델이 실제 번역을 작성하고 MCP가 원문 제공·검사·저장만 담당한다. 모델 호출을 현재 구독 공유 API로 우회하지 않는다. 현재 UI 확인은 대화 작성기에서의 조합 확인이다. 메시지 전송 후에도 같은 모델이 도구를 호출하는지는 읽기 전용 시험으로 확인해야 한다. 앱을 붙일 수 있다는 사실만으로 자동 번역 성공을 주장하지 않는다.

기존 결과를 바꾸지 않는 확인 요청은 다음과 같다. 앱을 첨부한 대화에서 사용자가 보낸다.

```text
get_translation_job 도구를 jobId "5b064194-0a5d-4bf3-865e-cfd9161d571d"로 한 번 호출해 회차, 전체 자막 수, 저장된 분할 수만 알려줘. 번역 저장·문맥 변경·finalize는 하지 마. 도구를 사용할 수 없으면 그대로 알려줘.
```

실제 선택 화면과 전송 전 요청은 개인 `private-subtitles/chatgpt-plan/chat-gpt6-pro-ottspeed-selected.png`, `chat-gpt6-pro-mcp-probe-draft.png`에 보존한다. 공개 화면 자동 제출은 사용자의 이전 선호에 따라 수행하지 않았다.

## 도구 조합이 지원되지 않는 경우

Pro에서 파일 번역이 가능하면 기존 고정 요청 JSON을 업로드해 번역 응답 JSON을 파일로 받고 OTTSpeed 기존 응답 검사·B 생성 경로로 가져오는 방식을 사용할 수 있다. 이 파일 왕복의 **GPT-6 Pro 실제 실행**은 아직 시험하지 않았다. ID·시간·원문 해시를 유지하는 기존 파일 교환 계약을 사용하며 자연어 답변을 완료 자막으로 취급하지 않는다.

개인 Pro의 Chat 대화 `6-pro`를 외부에서 시작·재개시키는 공식 호출 API는 이번 조사에서 확인하지 못했다. MCP 연결은 모델 실행 트리거가 아니다. 현재 확인한 활용 후보는 사용자가 대화를 시작하는 복사+MCP 또는 파일 왕복이며, 무인 연속 실행과 구분한다.

기존 MCP의 선행 맥락 정책은 S01~S02E02에 고정돼 있다. 새 전 시즌 대기열에 그대로 적용하지 않고 회차별 허용 선행 맥락을 연결하는 변경이 필요하다. 전 시즌 영어 수집 완료와 전 시즌 번역 실행 준비 완료를 구분한다.
