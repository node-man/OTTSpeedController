# OTT Speed Controller

OTT 서비스 및 모든 웹사이트의 비디오 재생속도를 자유롭게 조절할 수 있는 크롬 확장프로그램입니다.

## 주요 기능

- 🎚️ **재생속도 조절**: 0.25x ~ 4.0x 범위에서 자유롭게 조절
- 🎯 **프리셋 버튼**: 자주 사용하는 속도 원클릭 선택 (0.5x, 0.75x, 1.0x, 1.5x, 2.0x)
- 💾 **속도 저장**: 설정한 속도가 자동으로 저장됩니다
- 🎨 **상태 표시**: 비디오 재생/정지 상태에 따라 아이콘 색상 변경
- ⌨️ **단축키 지원**: Ctrl + ↑/↓ 또는 Ctrl + [ / ] 로 속도 조절

## 설치 방법

1. 이 폴더를 다운로드합니다
2. Chrome 브라우저에서 `chrome://extensions` 접속
3. 우측 상단의 **"개발자 모드"** 활성화
4. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
5. 다운로드한 `OTTSpeed` 폴더 선택

## 사용 방법

1. 비디오가 있는 웹사이트 방문 (넷플릭스, 유튜브, 웨이브, 티빙 등)
2. 확장프로그램 아이콘 클릭
3. 슬라이더 또는 프리셋 버튼으로 원하는 속도 선택

### 단축키

| 단축키 | 기능 |
|--------|------|
| `Ctrl + ↑` 또는 `Ctrl + ]` | 속도 +0.25x |
| `Ctrl + ↓` 또는 `Ctrl + [` | 속도 -0.25x |
| `Ctrl + 0` | 기본 속도 (1.0x) |

## 파일 구조

```
OTTSpeed/
├── manifest.json          # 확장프로그램 설정
├── popup/
│   ├── popup.html         # 팝업 UI
│   ├── popup.css          # 팝업 스타일
│   └── popup.js           # 팝업 로직
├── scripts/
│   ├── content.js         # 비디오 제어
│   └── background.js      # 아이콘 상태 관리
├── icons/                 # 아이콘 파일
└── tools/                 # 개발 도구
```
