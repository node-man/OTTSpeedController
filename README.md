# OTTDeck · 자막·번역·시청 도구

**OTTDeck**은 기존 OTTSpeed를 이어가는 Chrome Manifest V3 확장입니다. 재생 속도를 조절하고, 보유한 영문·한글 자막을 영상 위에 표시하며, 기존 번역과 새 번역을 A/B로 비교합니다.

**v1.2.0은 자막·번역 기능 개발 버전입니다.** 수동 파일 교환에 더해 Netflix 영어 자막 파일 수집과 일반 ChatGPT MCP 번역 브리지를 제공합니다. 실제 S02E03 영어 파일 1,831개 항목 전량 수집을 확인했습니다. ChatGPT 번역·실제 표시 상태는 수집 성공과 별도로 확인합니다. [수집 검사](docs/NETFLIX_CAPTURE.md) · [ChatGPT MCP 연결](docs/CHATGPT_MCP.md)

## 들어 있는 기능

| 영역 | 기능 |
|---|---|
| 배속 | 0.25–4×, 팝업 프리셋, Ctrl/Cmd 단축키, 마지막 속도 저장 |
| 자막 입력 | SRT/VTT, 영문 원문 + 한글 A + 한글 B, 파일당 5 MB·20,000개 cue 제한 |
| 비교 | 한글·영문·영한 병기, A/B 전환, 글자 크기·위치 조절 |
| 동기화 | 공통 offset/시간 배율 + 원문/A/B 각각의 추가 offset/배율 |
| 번역 왕복 | 새 번역·기존 한글 교정 요청 JSON, 요청·원문·영상·자막 ID 검증 후 B로 가져오기 |
| 저장 | 영상별 자막·설정·현재 번역 요청을 브라우저 IndexedDB에 저장 |
| 자막 라이브러리 | 재생 탭 없이 작품·시즌·회차, 영어/A/B와 이전 버전, 진행·연결 검사 조회·검색·미리보기·백업/복원 |

| 공개된 자막 | HTML TextTrack의 현재 접근 가능한 cue를 원문으로 가져오기 |
| Netflix 수집 | 현재 회차 manifest의 영어 자막 파일 수집·범위·해시·입력 항목 대조 |

| ChatGPT MCP | 앞에서부터 번역된 범위를 B로 먼저 수신·시청, 나머지는 자동 추가하고 전편 완료 시 별도 확정 |
| 내보내기 | 선택한 한글의 SRT/VTT 저장. 표시 보정값을 제외한 파일 원래 시간 유지 |

후속 동시 시청 시험에서는 **E05 재생 중 E06 영어 2,236개 전량 확보**를 확인했습니다. 시청 전·중·후 재생 상태와 실제 파일 검사 결과를 [동시 시청 시험 기록](docs/CONCURRENT_HEADLESS_CAPTURE.md)에 남겼습니다.

Netflix 팝업의 **번역 시작**은 현재 회차의 영어 전편·번역 작업을 준비합니다. [Workspace Agents 공식 연결](docs/WORKSPACE_AGENTS.md)이 설정돼 있으면 브리지가 실행을 요청하고, 미설정이면 프롬프트를 복사해 ChatGPT의 OTTSpeed 앱에 보내는 흐름을 유지합니다. 작업실이나 ChatGPT 탭은 자동으로 열리지 않습니다. 두 방식 모두 MCP에 저장된 결과를 확장 백그라운드가 받고, 첫 구간부터 **처음부터 B로 재생**할 수 있습니다. 공식 실행의 실계정 연결·번역 반환은 별도 확인 대상입니다.

Netflix/YouTube는 URL의 영상 ID에 세션을 연결합니다. 일반 웹사이트와 파일 페이지는 문서·video·소스 세대에 연결하므로 페이지를 새로 열면 자막을 다시 선택합니다. 회차가 바뀌면 이전 자막을 지웁니다.

팝업의 **자막 라이브러리**는 영상 없이도 열립니다. 저장된 영어·A/B를 확인하고, 작품·시즌·회차를 정리하며 버전별로 내보내거나 백업할 수 있습니다. **선택 회차 번역 준비**는 이미 수집된 원문으로 작업 묶음을 만듭니다. 미수집 회차의 자동 확보와는 구분합니다. [라이브러리·일괄 준비](docs/SUBTITLE_LIBRARY.md)

로컬 브리지가 실행 중이면 라이브러리가 PC 수집 보관소도 연결합니다. 실제 확보한 The West Wing **156회차**의 작품·시즌·회차·제목과 완료된 번역을 가져오며 기존 A/B 선택은 유지합니다. S02E06의 Astra high 전편 B **2,236개**도 별도 버전으로 보관합니다. 수집 보관소의 원문과 요청·결과·시각 검증을 통과한 자료만 가져오고 번역을 다시 호출하지 않습니다. 업데이트 전에 열어 둔 라이브러리 페이지는 새로고침해야 합니다.

새 **Netflix 사전 수집**은 회차 주소를 등록하면 사용자 탭 조작 없이 수집하도록 만든 대기열입니다. Chrome 실행·Netflix 로그인이 필요하며, 설치 확장에서의 실제 Netflix 수집 성공은 아직 확인하지 못했습니다. [백그라운드 수집 범위·검증 상태](docs/BACKGROUND_COLLECTION.md)

라이브러리의 비활성 탭 대기열은 **실험 기능**입니다. 별도 [로그인된 headless 도구](docs/HEADLESS_CAPTURE.md)는 실제 E03·E04 영어 전체 파일 수집과 독립 검사를 통과했습니다. 최초 1회 `npm run netflix:login`으로 전용 프로필에 정상 로그인한 뒤 `npm run netflix:capture -- --video-id 70262108`처럼 창 없이 실행합니다. 확장 팝업·라이브러리 자동 연결과 시즌 회차 자동 발견은 별도입니다.

개인 Pro 이용 시에는 **프롬프트 복사 + ChatGPT OTTSpeed 앱의 MCP 번역**을 기본으로 사용합니다. 라이브러리의 공식 자동 실행 버튼은 해당 연결이 준비된 경우에만 표시합니다. Workspace Agents의 계정 지원 조건과 선택적 설정은 [별도 문서](docs/WORKSPACE_AGENTS.md)에 있습니다.

## OTTDeck으로 이름 변경

프로젝트·저장소는 **OTTDeck / ottdeck**으로 바뀌었습니다. 기존 설치의 확장 ID·IndexedDB·번역 요청 형식·브리지 페어링·터널·네이티브 도우미 ID는 유지합니다. 이름 변경을 위해 진행 중인 번역이나 저장 자료를 초기화하지 않습니다.

**기존 사용자는 새 폴더를 별도 확장으로 로드하지 마세요.** 번역이 끝난 뒤 새 패키지의 파일을 기존에 설치한 폴더에 덮어쓰고 같은 확장을 새로고침합니다. 설치 폴더를 바꾸거나 기존 확장을 제거하면 확장 ID와 자막 저장소가 달라질 수 있습니다. 현재 로컬 설치 경로의 OTTSpeed 이름은 호환을 위해 유지합니다.

[모듈 구조와 기능 추가 방법](docs/ARCHITECTURE.md) · [기존 연결 보존 정책](docs/COMPATIBILITY.md)

## 설치

1. 이 브랜치의 소스를 다운로드해 압축을 풉니다.
2. Chrome에서 `chrome://extensions`를 엽니다.
3. **개발자 모드 → 압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
4. `manifest.json`이 있는 저장소 폴더를 선택합니다.
5. 이미 열려 있던 영상 탭을 새로고침합니다.

확장 설치에는 빌드 과정이나 `npm install`이 필요하지 않습니다. PC의 MCP 브리지와 개발 검사를 실행할 때는 Node 20 이상에서 `npm ci`가 필요합니다. 개발용 파일을 제외한 확장 폴더는 `npm run package`로 만들고 `dist/OTTDeck-1.2.0`을 로드하세요. 파일 페이지는 Chrome 확장 설정에서 **파일 URL에 대한 액세스 허용**이 필요합니다.

Windows의 번역 연결은 `npm run runtime:install`로 로컬 도우미를 한 번 등록한 뒤 확장을 새로고침하면 됩니다. 팝업의 **번역 연결 시작**, 팝업 열기·번역 시작·Chrome 시작 때 브리지와 터널을 준비합니다. 이미 실행 중인 연결은 유지합니다. `nativeMessaging` 권한을 사용하며 도우미는 OTTSpeed 확장 한 개의 시작·상태 조회만 허용합니다. [설정과 실제 검증 범위](docs/CHATGPT_MCP.md#확장에서-연결-시작-windows)를 참고하세요.

## 처음 사용하기

1. Netflix·YouTube 등에서 영상을 연 뒤 OTTSpeed 아이콘을 누릅니다.
2. **자막·번역 작업실 열기**를 누릅니다. 작업실은 처음 선택한 영상 탭에 계속 연결됩니다.
3. 같은 회차의 **영문 원문**, **기존 한글 A**를 불러옵니다. 비교할 파일이 있으면 B에도 불러옵니다.
4. 영상 탭으로 돌아가 초반·중반·후반의 시간을 확인합니다.
5. **한글 자막 A/B**와 **표시 방식**을 바꾸며 비교합니다. 작업실을 닫아도 현재 영상의 표시가 이어집니다.

독립적으로 작성한 3개 대사의 예시는 `examples/demo.en.vtt`, `examples/demo.ko.vtt`에 있습니다. 실제 작품 자막은 이 저장소에 포함하지 않습니다.

### 시간 맞추기

양수 offset은 자막을 늦게, 음수는 일찍 보여줍니다. 재생 배속과 자막 시간 배율은 서로 다른 설정입니다. 자막은 항상 `video.currentTime`을 기준으로 표시되며 2× 재생에서도 별도 시간 보정이 필요하지 않습니다.

```text
표시 시각 = 파일 시각 × 공통 배율 × 트랙 배율
          + 공통 시간 보정 + 트랙 시간 보정
```

예를 들어 Netflix에서 가져온 영문은 이미 맞고, 보유 한글 A만 2초 늦춰야 한다면 **공통 보정 0초**, **영문 트랙 0초**, **A 트랙 +2초**로 설정합니다. A를 교정한 B는 요청 생성 시점의 A 트랙 보정을 이어받습니다. 영문에서 새로 번역한 B는 영문 트랙 보정을 이어받습니다.

앞은 맞지만 뒤에서 일정 비율로 벌어지면 시간 배율을 조절합니다. 인트로·광고·삭제 장면·판본 차이에 따른 구간별 불일치는 offset/배율 하나로 해결되지 않습니다. 이번 버전에는 구간별 정렬이나 음성 기반 자동 정렬이 없습니다.

### 번역 파일 왕복

1. **기존 한글 교정** 또는 **새로 번역**을 선택합니다.
2. **번역 요청 JSON 저장**을 누릅니다. 교정은 현재 선택한 A/B의 슬롯, 새 번역은 영문의 슬롯을 유지합니다. 새 번역에도 한글 A가 있으면 참고 자료로 포함하며, B의 시간 보정은 영문 트랙을 따릅니다.
3. 요청 파일과 작업실의 안내문을 ChatGPT에 전달합니다.
4. `outputTemplate` 형식으로 반환된 완전한 **응답 JSON 파일**을 가져옵니다.
5. 요청 ID·SHA-256·영상 ID·모든 cue ID 검증을 통과하면 B에 적용합니다. A는 변경하지 않습니다.

결과 가져오기는 현재 B를 대체하며 이전 문안은 라이브러리 버전으로 보관합니다. 별도 파일이 필요하면 B를 VTT/SRT로 저장할 수 있습니다. 다른 자막 파일을 불러오거나 새 요청을 생성하면 현재 요청이 대체됩니다. 파일 교환 UI는 완전한 응답만 받으며, 일부 cue가 빠진 결과를 완성본처럼 저장하지 않습니다. MCP 분할 수신과 브라우저 밖 파일 교환 도구는 별도 경로입니다.

브라우저 밖에서 준비한 분할 작업은 작은 [파일 교환 도구](docs/FILE_EXCHANGE.md)로 병합·검증할 수 있습니다. 이 도구는 기존 코어 계약을 사용하며, 전체 검증 후 만든 B VTT를 작업실에 직접 불러옵니다. 작업실 UI의 부분 응답 가져오기는 지원하지 않습니다.

이미 번역된 SRT/VTT는 B에 직접 불러올 수도 있습니다. 이 경로에서는 JSON의 원문 해시·응답 ID 대조를 수행하지 않습니다. 시간 구조는 파서가 검증하고 회차·의미는 사용자가 확인합니다.

### 보유한 전 시즌 자막 활용

개인적으로 보유한 자막을 로컬 파일로 불러와 사용합니다. 같은 배포본에 포함된 영어·한글을 먼저 사용하면 상호 문맥 대조가 쉽습니다. 영어와 한국어의 cue 개수는 달라도 되며 번호로 일대일 연결하지 않습니다.

원문과 기존 한글을 함께 보내 **정치·법률 용어, 생략된 주어, 인물 간 말투, 풍자·농담, 의미 누락**을 검토합니다. 기존 번역 전체를 정답으로 가정하거나, 작품 속 의도적인 말실수를 사실에 맞춰 임의로 바꾸지 않습니다. 장기적으로 검토된 번역 쌍과 용어집을 축적하는 단계는 [프로젝트 문서](docs/PROJECT.md)에 정리했습니다.

## 단축키

| 단축키 | 동작 |
|---|---|
| Ctrl/Cmd + ↑ 또는 ] | 속도 +0.25× |
| Ctrl/Cmd + ↓ 또는 [ | 속도 −0.25× |
| Ctrl/Cmd + 0 | 1×로 재설정 |

입력창·선택 상자·편집 가능한 요소 및 IME 조합 중에는 가로채지 않습니다. 웹사이트나 브라우저가 단축키를 먼저 처리하는 경우 팝업을 사용하세요.

## 현재 한계

- Netflix 전체 파일 수집은 S02E03에서 확인했습니다. 다른 회차·트랙·프로필은 수집 시마다 범위를 검사합니다. HTML TextTrack 가져오기는 별도 경로이며 일부 구간만 있을 수 있습니다.
- 플레이어 **컨테이너 전체화면**은 지원하는 구조입니다. `<video>` 요소 자체 전체화면에서는 한계를 안내하고 기본 자막을 복원합니다. 실제 사이트별 확인이 필요합니다.
- 일반 DOM과 열린 Shadow DOM의 video를 찾습니다. 닫힌 Shadow DOM·다른 iframe 안의 영상·Picture-in-Picture 자막은 지원 범위 밖입니다. 여러 영상이 있으면 화면에서 가장 크게 보이는 영상을 우선합니다.
- SMI 직접 불러오기, 자동 대사 전사, 번역 모델 API 호출, 로컬 모델 실행, 구간별 자동 정렬은 지원 범위 밖입니다.
- 이 버전은 일반 텍스트 자막을 표시합니다. VTT 스타일·위치 정보·색상·화자별 배치는 재현하지 않습니다.
- 자막 파일은 해당 브라우저 프로필에 저장됩니다. 확장 제거·브라우저 저장 공간 정리 시 사라질 수 있어 원본과 결과 파일을 별도로 보관하세요.
- Netflix/YouTube의 광고·인트로·판본 변경이 같은 영상 ID 안에서 발생할 때 시간 일치를 자동 판정하지 않습니다. 처음·중간·끝을 실제로 확인하세요.

## 데이터와 권한

확장에는 분석 SDK나 번역 모델 API 호출이 없습니다. 사용자가 MCP 번역을 준비하면 Netflix 영어 원문이 PC의 로컬 브리지에 저장되며 연결한 일반 ChatGPT가 도구로 읽고 번역 결과를 저장합니다. 수동 파일 교환도 유지합니다. 별도 호스트 도구에는 [전 시즌 headless 수집 대기열](docs/SERIES_COLLECTION.md)과 사용자 동의 후 실행하는 [공식 ChatGPT 요금제 연동 시험](docs/CHATGPT_PLAN_USAGE.md)이 있습니다. 웹페이지에서 읽은 자막은 실행 코드가 아닌 문자열로 취급하며 오버레이에는 `textContent`를 사용합니다.

기존 `activeTab`, `storage`, `scripting`과 `<all_urls>` content script 범위를 유지합니다. 프롬프트 복사는 `clipboardWrite`, 백그라운드 수신 재개는 `alarms`를 사용합니다. 로컬 브리지 통신에는 `http://127.0.0.1/*` host 권한을 사용하고 허용 Origin·토큰을 별도로 검사합니다. Workspace Agent 토큰과 외부 호출은 로컬 브리지에만 두며 확장의 외부 사이트 권한을 추가하지 않습니다. `<all_urls>`는 여러 사이트의 video 감지를 위해 기존부터 있던 접근 범위입니다.
